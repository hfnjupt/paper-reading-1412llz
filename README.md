# paper-reading-1412llz

面向论文阅读的 Codex Skill：精读生成 Obsidian 笔记，粗读生成固定九列 Excel 台账。入口为 [SKILL.md](SKILL.md)。

## 输入

- 单个 PDF、DOI、论文网页或题目。
- PDF 文件夹，可按文件名、子目录或主题筛选并顺序处理。
- 可选 Word、Markdown 或文本研究背景，用于相关性分析与研究迁移。

## 精读输出

- 完整摘要原文与中文翻译。
- 依据引言梳理背景、已有方法不足、本文方案和贡献。
- 总结相关工作的分类逻辑及各类方法的不足。
- 逐模块解释技术选择原因、机制和预期作用，并保留对应英文原句与页码。
- 在方法、损失与实验段落内嵌原论文局部截图；公式只裁公式与编号。
- 详细记录实验设置，按实际验证维度概述实验结果。
- 分开记录作者主张、论文证据、阅读推断与外部资料，保留冲突和不确定性。

Obsidian 笔记使用 `.md` 加相对路径 `assets/` 图片附件。导入时保留整篇目录结构即可显示图片。

## 粗读输出

固定列：论文题目、作者及机构、摘要、关键词、针对的问题、解决的方法、创新以及借鉴地方、代码位置、批判地方。

- 题目列只保留题目。
- 作者列只保留作者、机构、期刊/会议及发表年份；第一作者与已确认的通讯作者局部加粗。
- 摘要列紧邻作者列：同一单元格先放完整英文摘要，再空行附完整中文翻译；不省略原文或译文，缺失时明确标注。
- 问题列说明摘要和引言中的背景与具体问题。
- 方法列说明方法名称、核心思想、逻辑和组成；实验仅列数据集与验证维度，数据集名称局部加粗，不罗列指标。
- DOI、作者身份依据和阅读范围等保存在配套追溯记录中。

## 使用示例

在已配置此 Skill 的环境中：

```text
使用 $paper-reading-1412llz 精读这篇 PDF，生成带方法框图、损失公式截图和英文摘录的 Obsidian 笔记。
```

```text
使用 $paper-reading-1412llz 粗读这个文件夹，只处理文件名包含 cross-modal 的论文，并输出 Excel。
```

```text
使用 $paper-reading-1412llz，结合我提供的研究背景 Word，判断这些论文的相关性及可借鉴内容。
```

## 运行依赖

这是一套代理阅读工作流及辅助脚本，不是自动完成阅读的独立程序。PDF 预检使用 `pypdf`，页面渲染使用 Poppler `pdftoppm`，裁图使用 Pillow；Word 提取按脚本要求使用相应依赖。Excel 构建依赖 Codex 工作区提供的 Node.js 与 `@oai/artifact-tool`；富文本辅助脚本使用 Python 标准库。优先使用所在环境提供的捆绑依赖，具体协议见 [Excel 输出规范](references/excel-output.md)。

将仓库作为完整目录保存，保持 `SKILL.md`、`references/`、`scripts/`、`assets/` 和 `agents/` 的相对位置不变。参考设计项目见 [设计来源](references/design-provenance.md)。

## 范围

不将粗读伪装为全文精读；下载失败会明确报告。不使用模型记忆补写实验数字、缺失正文或引用信息。仓库只保存 Skill 及其模板，不包含论文 PDF、用户研究背景或生成的阅读笔记。
